Finish a partial WordPress installation

{% include "servers/_snapshot_notice.html" with notice=site_page.stale %}

An installation that stopped partway leaves this site behind its provisioning gate, with some of its release files, configuration or database tables in place. A Finish review reads the server and proposes only the missing resources that it can verify, then the reviewed change from the gate to the ready routing. It needs no record of the earlier run, so it works from any controller. Preparing it changes nothing on the server and starts no WordPress code.

  • It compares every existing release file with a copy of the pinned archive and replaces none. Edited, foreign or ambiguous files, a private configuration outside the supported grammar and a site file that is not the exact gate are refused.
  • It never replays core installation into a database that holds any WordPress table, rotates a salt, resets an administrator or deletes a file or table. A database that is wholly empty gets one core installation; a database that already holds exactly the installed schema keeps its administrator and needs no password step.
  • Applying a review is a separate action on its plan page with its own permission. It runs one native unit that outlives this page and is never submitted twice.
