Barectl runs this site's Laravel schedule every minute as s{{ identifier }}, from its current release and its selected PHP. Each run is limited to one hour and the whole run is stopped at that limit. A slow run delays the next one instead of overlapping it, and runs missed while the server is down are not caught up.

Schedules more frequent than once a minute are not supported. Tasks that keep working after the run through runInBackground are stopped at the run's limit, so work that must outlive the run is not supported.
