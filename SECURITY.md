# Security

Barectl is in early development. No release has been designated production-ready.

Do not post credentials, private hostnames, or exploit details in public issues. Report suspected vulnerabilities privately to the repository maintainer using the contact link on https://github.com/rajandangi. If private vulnerability reporting is enabled on this repository, use its Security tab.

Include the affected revision, reproduction steps, impact, and a minimal example with secrets removed. Response times are not guaranteed.
