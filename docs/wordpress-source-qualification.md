# Approved-source WordPress qualification

This record covers the extension profile and WordPress operations for PHP 8.3, 8.4 and 8.5 from the approved unified PHP source, requested by [#320](https://github.com/rajandangi/barectl/issues/320). It supplements the historical [v0.4 qualification record](v0.4-qualification.md); it does not assign earlier Ubuntu-package or reboot evidence to these combinations. The six arm64 release/branch combinations below are admitted after the combined local native evidence recorded here. amd64 combinations remain disabled. The evidence was collected on the uncommitted implementation based on `8a7086fbed28856186c82b9d81bd37da967dfd68`; exact-head hosted results are still required for final acceptance. This record claims no release or production installation.

Implementation revision: [`a0a90aa34847253678cfb8b3a095d48e5b2f6e01`](https://github.com/rajandangi/barectl/commit/a0a90aa34847253678cfb8b3a095d48e5b2f6e01).
