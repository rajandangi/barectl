# Review exact bootstrap transitions

> For new servers, bootstrap installs the target stack ([ADR 0026](0026-manage-fresh-hosts-on-one-target-stack.md), [ADR 0027](0027-serve-sites-and-https-with-caddy.md), [ADR 0028](0028-supply-runtimes-and-tools-from-pinned-nix.md)), and reviews are stored once by the change engine of [ADR 0035](0035-one-change-engine-with-effect-derived-consent.md).

For v0.2 bootstrap, Barectl owns an immutable configuration plan bound to fresh native evidence and exact package transitions. Pyinfra provides transport; its prepare phase is not a stored executable plan, so Barectl dispatches fixed native actions rather than compiling its internal operations. Bootstrap installs only distribution-default Nginx and PHP components on qualified Ubuntu 24.04 and 26.04 servers, each from its own release ([ADR 0008](0008-review-each-ubuntu-release-by-its-own-policy.md)), refusing customized stacks and installed-package upgrades to keep the first mutation contract verifiable.

Plan preparation and the immutable plan record are implemented: a read-only worker operation reviews native evidence against the profile rules and stores the decision, exact transitions from `apt-get -s`, effects, postconditions, refusal reasons and evidence fingerprints, bound to the boot ID and a deadline on `/proc/uptime`. Every plan also keeps the raw APT digest the apply payload recomputes on the server under the mutation lock, and a package plan a package digest of dpkg's status, automatic marks, downloaded indexes, units, configuration and listeners; each is read twice during preparation so evidence changing mid-read is refused. Package plans refuse sources other than `http` and `https` archives, and installation plans refuse an expired Ubuntu Release file. Applying goes through [ADR 0006](0006-use-native-bootstrap-execution.md) for metadata refresh, cleanup of finished runs and the Nginx and PHP profiles.

APT simulation does not lock execution. A per-invocation pre-install guard matches APT's actual transaction to the approved plan before dpkg changes packages ([ADR 0007](0007-admit-exact-package-transactions-with-an-inline-apt-guard.md)); it is qualified against apt 2.8.3 on Ubuntu 24.04 and apt 3.2.0 on Ubuntu 26.04. Metadata refresh requires separate review, and native service-start/restart effects appear in the plan. The detailed contract and upstream sources are in [v0.2](../v0.2.md#review-and-package-admission).
